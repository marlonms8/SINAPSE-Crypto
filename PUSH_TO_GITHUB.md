# Publicar em marlonms8/SINAPSE-Crypto

## 1. Crie o repositório

No GitHub, crie um repositório vazio chamado:

`SINAPSE-Crypto`

Não marque as opções para criar README, `.gitignore` ou licença, pois estes arquivos já estão incluídos.

## 2. No terminal, dentro da pasta do projeto

```bash
git init
git add .
git commit -m "Initial release: SINAPSE Crypto 1.0.0"
git branch -M main
git remote add origin https://github.com/marlonms8/SINAPSE-Crypto.git
git push -u origin main
```

## 3. Release sugerida

Tag: `v1.0.0`

Título: `SINAPSE Crypto 1.0.0`

Depois que o APK de release estiver assinado, ele pode ser anexado à Release do GitHub.
