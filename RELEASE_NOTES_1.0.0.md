# SINAPSE Crypto 1.0.0

Primeira versão pública estável do **SINAPSE Crypto**.

## Recursos
- Criptografar e descriptografar textos.
- Compatibilidade AES/CBC com SINAPSE/Collura.
- Funcionamento totalmente offline.
- Texto de entrada editável em tela cheia.
- Resultado estritamente somente leitura.
- Resultado ampliável em tela cheia, sem abertura do teclado.
- Rolagem para textos longos.
- Botão Copiar.
- Mostrar/ocultar chave de segurança.
